👉 Now Open Swagger UI & Click "Authorize 🔓"
1
Understand the Green "Authorize 🔓" Button
The key to unlocking protected endpoints

Most endpoints in AuthCore (like creating roles or managing users) are protected by JWT Bearer authentication. When you first open Swagger UI, trying to call them directly will return 401 Unauthorized or 403 Forbidden.

How to Authorize:
1. Look at the top right of Swagger UI for the green "Authorize 🔓" button.
2. Click it — a modal pops up asking for Value:.
3. Paste your accessToken (just the token, no quotes, no "Bearer " prefix).
4. Click Authorize, then click Close.
5. The padlock icon will change to locked 🔒. You are now fully authenticated!
2
Login Manually via Swagger (Alternative)
If you prefer doing it manually inside Swagger

Inside Swagger, expand the Authentication section and locate POST /api/v1/auth/login.

  1. Click anywhere on the blue bar for POST /api/v1/auth/login to open it.
  2. In the Request body text area, paste this payload:
{
  "email": "superadmin@authcore.io",
  "password": "AdminPassword123!"
}
  1. Click the blue Execute button.
  2. Look right below under Server response (200).
  3. Highlight and copy the long string inside "accessToken": "...".
  4. Scroll up to the top and paste it into the green Authorize 🔓 button!
3
Test Creating a Role (Role Management)
POST /api/v1/roles

Now that you are authorized, let's create a custom role with specific permissions: 

{
  "name": "COMPLIANCE_MANAGER",
  "description": "Responsible for privacy and audit inspections",
  "permissions": [
    "audit:read",
    "users:read",
    "sessions:read"
  ]
}
Execution: Click on POST /api/v1/roles → Paste the JSON above into Request body → Click Execute.
Expected Response: 201 Created with the created role details and generated UUID!
4
Test Assigning a Role to a User
POST /api/v1/users/{id}/roles

Assign the newly created role to the pre-seeded user John Doe:

Parameter Value
id (Path Parameter) ededffff-5b88-4a95-8e12-72f5b6ff8085 
{
  "roleName": "COMPLIANCE_MANAGER"
}
Execution: In the User Management section → Click POST /api/v1/users/{id}/roles → Type John's UUID in the id box → Paste the JSON body → Click Execute.
Expected Response: 200 OK showing John Doe now has both USER and COMPLIANCE_MANAGER roles!

Troubleshooting & Error Codes
What to do if something goes wrong
Status Code Meaning How to Fix
401 Unauthorized Missing or expired token Click the green Authorize 🔓 button at the top and paste a fresh token from /login. (Tokens expire after 15 minutes).
403 Forbidden Insufficient permissions Ensure you are logged in with superadmin@authcore.io. Standard users cannot create or assign roles.
409 Conflict Duplicate resource A role or user with this exact name/email already exists. Pick a different name.
429 Too Many Requests Rate limit hit (BR-21) Max 5 login attempts per 15 minutes from the same IP. Wait a couple of minutes or use a different client.
